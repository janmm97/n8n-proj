# Multi-Agent Content Automation

Two related workflows that generate, organize, and prepare social content:

- `content-generator.json` — the multi-agent content writer: an idea agent, platform-specific writing agents for LinkedIn and X, sheet storage, and an image prompt chain.
- `n8n-ai-content-workflow.json` — an earlier AI content workflow: a webhook trigger, LinkedIn/X/blog generators, structured content processing, and an optional database save.
